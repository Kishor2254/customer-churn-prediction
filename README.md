# Customer Churn Prediction System

## 📌 Description
This project predicts whether a customer will leave a company based on behavioral and service usage data. It helps businesses improve customer retention and reduce revenue loss.

## ⚙️ Features
- Exploratory Data Analysis (EDA)
- Feature engineering and encoding
- Handling class imbalance using SMOTE

## 🧠 Algorithms Used
- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- XGBoost
- Gradient Boosting

## 📊 Evaluation Metrics
Accuracy, Precision, Recall, F1-score, ROC-AUC

## 🛠️ Technologies Used
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## 🎯 Objective
To identify customers at risk of churn and support business retention strategies.
